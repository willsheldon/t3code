# My tasks

Agents sometimes need you to do something only you can do: run a command on a machine they cannot
reach, approve a change, or decide. They record it as a task, so it does not stay buried in a
thread's history.

On web and desktop, open **My tasks** in the sidebar, next to Pull requests. The badge counts the
tasks waiting on you. The page appears when a connected server supports tasks.

Each task shows what to do, the thread that is waiting (select it to open the thread), the steps
with copyable commands, the project, and a deadline if the agent gave one. Tasks are grouped as
**Due today or overdue**, **Waiting on you**, and **Done in the last 7 days**.

- **Done** marks the task done and sends the thread one message that you did it, so the thread
  continues without you opening it. Selecting Done twice sends one message. If sending fails, the
  task stays open with the error; select **Retry**.
- **Reply** sends the thread a message and leaves the task open.
- **Reopen** puts a done or closed task back on the list.

An agent can close its own task when it sees the result for itself. The task then shows **Closed by
the thread**. A thread that is archived, or that cannot receive messages, gets no message from
Done, and the task says so. A task stays on the page after its thread is archived and shows
**Thread archived**. Deleting a thread removes its tasks.
